# SG Video Scanner

A responsive, dark-themed front-end prototype for a creator video pre-publish workspace.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required.

## Prototype features

- Select or drag-and-drop a video file and preview it locally in the browser.
- Remove the selected video and choose another.
- Show a clearly labeled sample risk report interface.
- View Facebook, Instagram, and YouTube policy links and monetization context.
- Responsive mobile navigation and layout.

## Important limitation

This is a user-interface prototype only. It does **not** perform copyright matching, policy review, content analysis, or monetization eligibility checks. The report uses placeholder content and is not based on the uploaded video. Selected video files are previewed locally using a browser object URL; there is no upload backend or scanning engine.
